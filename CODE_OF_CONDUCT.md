# Code of conduct

ANS follows the [LF Projects Code of Conduct](https://lfprojects.org/policies/code-of-conduct/).
It applies to participation in the project's repositories and community spaces.

Report conduct concerns confidentially to the Manager of LF Projects at
[manager@lfprojects.org](mailto:manager@lfprojects.org). Include what happened,
when and where, and relevant supporting information. Do not publish sensitive
reports in a GitHub issue. The linked policy describes the reporting process.
